# Discord Moderation & Music Bot

بوت Discord احترافي مبني باستخدام Node.js و discord.js v14، يدعم أوامر بدون prefix، إدارة أعضاء، ميوت صوتي، إسكات كتابي، سجن Timeout، موسيقى YouTube، ونظام حماية للسيرفر.

## المميزات

- أوامر بدون prefix مثل `ميوت @user` و `اسكت @user` و `play اسم الأغنية`
- نظام صلاحيات للأدمن فقط
- ميوت صوتي مؤقت باستخدام Discord voice mute
- إسكات كتابي مؤقت باستخدام رتبة `Muted`
- سجن مؤقت باستخدام Discord Timeout
- فك الميوت، فك الإسكات، وفك السجن
- حذف آخر 30 رسالة مع تجنب خطأ رسائل أقدم من 14 يوم
- إعطاء الرتب بالاسم أو بالمنشن
- ترحيب تلقائي بالأعضاء الجدد
- تشغيل موسيقى من YouTube بالبحث عن اسم الأغنية
- Queue للأغاني مع أمر skip
- حماية من السبام والمنشن الجماعي وروابط دعوات Discord
- حماية من الدخول الجماعي Raid
- حماية من التخريب Nuke مثل حذف الرومات والرتب والباندات المتكررة
- تسجيل أخطاء كامل بدون إيقاف البوت

## المتطلبات

- Node.js 18 أو أحدث
- Ubuntu أو أي سيرفر Linux مناسب
- ffmpeg
- yt-dlp
- Discord bot token
- تفعيل intents من Discord Developer Portal

## تثبيت الحزم

داخل مجلد المشروع:

```bash
npm install discord.js dotenv ms @discordjs/voice yt-search @discordjs/opus
```

إذا تريد بطاقة ترحيب بالصورة:

```bash
npm install sharp
```

على Ubuntu:

```bash
sudo apt update
sudo apt install -y ffmpeg pipx
pipx ensurepath
pipx install yt-dlp
```

إذا كان `yt-dlp` مثبتًا مسبقًا، حدّثه:

```bash
pipx upgrade yt-dlp
```

## ملف .env

أنشئ ملف باسم `.env` داخل مجلد البوت:

```env
TOKEN=ضع_توكن_البوت_هنا
YT_DLP_PATH=/home/USERNAME/.local/bin/yt-dlp
OWNER_IDS=123456789012345678
WELCOME_IMAGE_PATH=/home/USERNAME/my_discord_bot/welcome-template.png
```

استبدل `USERNAME` باسم مستخدم السيرفر.  
مثال:

```env
YT_DLP_PATH=/home/crimeware/.local/bin/yt-dlp
```

يمكن إضافة أكثر من owner بهذا الشكل:

```env
OWNER_IDS=123456789012345678,987654321098765432
```

## نظام الصلاحيات

كل أوامر الإدارة والموسيقى مسموحة فقط لمن لديه:

- صلاحية Administrator
- أو رتبة اسمها `admin`
- أو رتبة اسمها `administrator`
- أو رتبة اسمها `ادمن`
- أو رتبة اسمها `أدمن`

إذا حاول شخص غير أدمن استخدام أمر، يرد البوت:

```text
❌ هذا الأمر مسموح فقط للأدمن.
```

## أوامر العقوبات

### ميوت صوتي

```text
ميوت @user
```

هذا الأمر يرسل قائمة لاختيار السبب، وبعد الاختيار يعمل ميوت صوتي للعضو داخل الروم الصوتي.

ملاحظات:

- العضو يجب أن يكون داخل روم صوتي
- البوت يحتاج صلاحية Mute Members
- لا يستخدم Timeout
- بعد انتهاء المدة يتم فك الميوت الصوتي تلقائيًا

### إسكات كتابي

```text
اسكت @user
```

هذا الأمر يعطي العضو رتبة `Muted` ويمنعه من الكتابة في الرومات النصية.

الرتبة تمنع:

- Send Messages
- Send Messages In Threads
- Create Public Threads
- Create Private Threads
- Add Reactions

### سجن Timeout

```text
سجن @user
```

هذا هو الأمر الوحيد الذي يستخدم Discord Timeout الرسمي.

## أسباب العقوبات

عند استخدام `ميوت` أو `اسكت` أو `سجن` تظهر قائمة اختيار:

- قذف: 1 ساعة
- مشاكل: 10 دقائق
- جدولة: 5 دقائق
- سبام: 5 دقائق
- إزعاج: 15 دقيقة

أسباب `سجن` فقط أصبحت:

- عنصرية: 1 ساعة
- تطرف: 6 ساعات
- شتم الذات الإلهية: أسبوع

بعد اختيار السبب، يرسل البوت Embed نجاح يحتوي:

- العضو
- السبب
- المدة
- النوع

## نظام Queue

- إذا كانت أغنية تعمل، الأغنية الجديدة تنضاف للقائمة
- عند انتهاء الأغنية، يشغل التالية تلقائيًا
- إذا انتهت القائمة، يخرج من الروم الصوتي
- إذا حصل خطأ في أغنية، يحاول تشغيل التالية ولا يطفي البوت

## تشغيل الموسيقى في أكثر من روم بنفس السيرفر

Discord لا يسمح لنفس حساب البوت أن يكون داخل أكثر من روم صوتي واحد في نفس السيرفر بنفس الوقت. لذلك يدعم الكود بوتات موسيقى مساعدة.

أضف توكنات بوتات إضافية في `.env`:

```env
MUSIC_TOKENS=توكن_بوت_موسيقى_1,توكن_بوت_موسيقى_2,توكن_بوت_موسيقى_3
```

كل توكن إضافي يعني روم صوتي إضافي يستطيع تشغيل أغاني بنفس الوقت داخل نفس السيرفر.

مثال:

- `TOKEN` يشغل روم واحد
- `TOKEN + MUSIC_TOKENS` فيه توكنين إضافيين = 3 رومات بنفس الوقت

لازم تدعو كل بوت موسيقى مساعد إلى السيرفر وتعطيه:

- View Channels
- Connect
- Speak

أوامر الموسيقى تبقى تنكتب للبوت الأساسي فقط، وهو يختار بوت موسيقى فاضي تلقائيًا.

لتثبيت كل بوت موسيقى داخل روم صوتي محدد، أضف:

```env
MUSIC_ROOM_MAP=music-1:Anonymous Cys.,music-2:Troy.,main:Null.
```

يمكنك استخدام اسم الروم أو ID الروم. الأفضل استخدام ID الروم إذا عندك رومات بأسماء متشابهة.

بعد هذا الإعداد:

- كل بوت يدخل رومه تلقائيًا عند تشغيل البوت
- إذا انتهت قائمة الأغاني، يبقى البوت داخل الروم
- إذا أحد عمل له Disconnect، يرجع لنفس الروم تلقائيًا
- البوت المرتبط بروم معين لن يشتغل في روم آخر

## حمايات السيرفر

### Anti Spam

إذا عضو غير أدمن أرسل 10 رسائل خلال 5 ثواني، البوت يعطيه رتبة `Muted` لمدة 5 دقائق.

### Anti Mass Mention

إذا عضو غير أدمن عمل منشنات كثيرة، مثل 8 منشنات أو أكثر، البوت يحذف رسالته ويعطيه `Muted` لمدة 10 دقائق.

### Anti Discord Invite

إذا عضو غير أدمن نشر رابط دعوة Discord مثل:

```text
discord.gg
discord.com/invite
discordapp.com/invite
```

البوت يحذف الرسالة ويعطيه `Muted` لمدة 10 دقائق.

### Anti Raid

إذا دخل 6 أعضاء خلال 10 ثواني، البوت يعتبرها محاولة Raid ويرسل تنبيه في روم اللوق.

إذا دخل حساب جديد عمره أقل من 3 أيام، يرسل البوت تنبيه.

### Anti Nuke

يراقب الأفعال الخطيرة:

- حذف رومات
- إنشاء رومات بسرعة
- حذف رتب
- إنشاء رتب بسرعة
- باندات متكررة

إذا نفس الشخص كرر 3 أفعال خطيرة خلال 30 ثانية، البوت يحاول:

- إزالة الرتب الخطيرة منه
- تطبيق Timeout لمدة ساعة
- إرسال تنبيه في روم اللوق

### رومات اللوق

البوت يبحث عن روم اسمه:

- logs
- log
- mod-log
- admin-log
- حماية
- الحماية

إذا لم يجد، يحاول استخدام روم النظام أو أي روم يستطيع الكتابة فيه.

## ملاحظات مهمة للحماية

الحماية لا تطبق على:

- البوتات
- مالك السيرفر
- الآيديات الموجودة في `OWNER_IDS`
- الأعضاء الأدمن في بعض حمايات الرسائل

يفضل وضع آيدي صاحب السيرفر في `OWNER_IDS`.

## مشاكل شائعة

### yt-dlp غير موجود

إذا ظهر خطأ مثل:

```text
yt-dlp غير مثبت أو YT_DLP_PATH غير صحيح
```

تحقق من المسار:

```bash
/home/USERNAME/.local/bin/yt-dlp --version
```

ثم ضعه في `.env`:

```env
YT_DLP_PATH=/home/USERNAME/.local/bin/yt-dlp
```

### خطأ 403 في YouTube

حدّث `yt-dlp`:

```bash
pipx upgrade yt-dlp
```

ثم أعد تشغيل البوت:

```bash
pm2 restart discord-bot --update-env
```

### البوت لا يقدر يعطي رتبة

تأكد من:

- البوت لديه Manage Roles
- رتبة البوت أعلى من الرتبة المطلوبة
- الرتبة ليست managed role خاصة ببوت أو Integration

### الميوت الصوتي لا يعمل

تأكد من:

- العضو داخل روم صوتي
- البوت لديه Mute Members
- رتبة البوت أعلى من العضو

### الإسكات الكتابي لا يعمل

تأكد من:

- رتبة البوت أعلى من `Muted`
- البوت لديه Manage Roles و Manage Channels
- صلاحيات القنوات تم تعديلها لرتبة `Muted`

## تحديثات الحماية

- كشف السبام داخل الرسالة الواحدة حتى لو كان مكتوبًا بنمط مكرر أو مفصول.
- كشف الألفاظ المسيئة حتى لو كانت ملغمة أو مكتوبة بحروف مفصولة.
- فلتر الألفاظ يحذف أول مخالفتين فقط، ثم يعطي اسكات 10 دقائق في الثالثة، و20 دقيقة عند التكرار بعدها.
- `info` يعرض العقوبات الفعلية فقط، ويخفي لوجات الحركة الصوتية.
